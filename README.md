# homebrew-esimtao

Official isolated Homebrew Tap for **esimtao.com**.

## Installation

```bash
brew tap AbigailDavised/esimtao
brew install esimtao-cli
```

## Quick Start

```bash
esimtao-cli --help
```

## Capabilities & Architecture
- Direct terminal client connecting to official MCP streamable HTTP endpoint: `https://esimtao.com/api/mcp`
- Zero sign-in, zero tracking, stateless calculations
- Website: https://esimtao.com
